## ClipSmith v1.0 · 片匠

把长视频切成「刚好能发出去」的小段，全程在手机上完成。

### 安装

下载下面的 `clipsmith.apk` 直接装。Android 9 以上，自签证书，安装时需要允许「安装未知来源应用」。

装好后建议给这几项权限，片库和悬浮球才能正常工作：

- 通知（进度显示）
- 照片和视频（片库列出片段）
- 所有文件访问（删除从电脑拷进来的片段时才需要）
- 悬浮窗（复制链接后弹出操作面板）

### 这个版本能做什么

- 贴 B站 / 抖音 / 快手链接直接下；多分P 和合集可以勾选多集排队
- 也可以直接选手机里的视频，不用先上传
- 按体积切段（默认每段 ≤9.6MB）或整条压到指定大小（比如 ≤12MB 一个文件）
- 跳过开头 / 裁掉结尾，先裁再压，片头不占算力
- 片库按视频分组，支持搜索、按组分选批量删除、微信「已发」标记与筛选
- 单段发微信 / 整组多选发 / 朋友圈
